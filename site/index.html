Serveur Kodistan

Interrègne

Un seul zip : Minecraft 1.21.1, NeoForge et tous les mods du serveur, déjà réglés. Tu double-cliques, tu te connectes, et tu arrives directement sur le serveur.

Télécharger le launcher Zip pour Windows

Le lien n'est pas encore en ligne : demande le zip aux organisateurs du serveur.

  1. I
    Décompresse le zip dans un dossier simple, par exemple C:\Jeux\Interregne. Évite le Bureau s'il est synchronisé par OneDrive.
  2. II
    Double-clique sur Jouer.bat. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires puis Exécuter quand même.
  3. III
    La première fois, connecte-toi avec le compte Microsoft qui possède Minecraft Java (Ajouter Microsoft, puis le code affiché).
  4. IV
    Relance Jouer.bat. Les mods se téléchargent (quelques minutes la première fois), puis le jeu s'ouvre directement sur le serveur. Ensuite, les mises à jour sont automatiques.

Java est téléchargé tout seul. Sur Mac ou Linux, le zip ne marche pas tel quel : installe Prism Launcher, puis importe l'instance Interregne.
